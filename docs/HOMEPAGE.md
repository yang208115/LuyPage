# 起始主页实现

## 页面与数据

- 默认 `/` 为起始主页，`/?view=library` 为管理页，`/?view=trash` 为回收站。没有明确 view 但含旧筛选参数的 URL 仍解析为管理页；清除管理筛选保留 library。
- 主页请求 `/api/homepage` 和分页常用列表，不请求完整布局索引或全部收藏。打开文件夹才请求对应分组，20 条常用／40 条文件夹收藏为一页。
- 主页摘要一次 D1 batch 读取账号版本、设置、分组计数与每组前四条简化收藏。预览按手动顺序，排除回收站，不返回备注和标签。
- 未分组显示在文件夹末尾。收藏图标复用内置图标选择；自动图标未接通时用彩色书签图标。

## 设置协议

`HomepagePreferences` 包含 `wallpaperId`（sunset-fields / blue-lake / night-forest）、`searchProvider`（bing / baidu / google / bookmarks）、`showClock`、`showCalendar`。默认田野夕阳、必应、两个组件显示。

- `GET /api/homepage` 返回 `{ revision, preferences, counts: { active, pinned }, folders: [{ id, name, count, preview: [{ id, title, url, icon }] }] }`。
- `PUT /api/homepage/preferences` 接受 `{ operationId, baseRevision, preferences }`，返回 `{ data: preferences, revision }`。沿用账号认证、来源检查、全局版本检查及幂等回执。
- `workspace_state.homepage_preferences` 独立于原 `preferences`；迁移提供既有账号默认值，旧布局保存或重置不会覆盖主页设置。
- 设置草稿保留在内存，取消撤销预览。网络失败保留相同操作编号以供重试；冲突提供读取最新值后重新编辑的流程。跨页和浏览器返回保护未保存设置与收藏草稿。
- 账号数据仍以 D1 为事实来源，不建立 localStorage 收藏或偏好副本。主页在窗口 focus 和重新可见时刷新账号设置，不受 15 秒查询缓存限制；已打开的设置草稿保持独立，取消后显示最新已保存值。

## 视觉与素材

桌面主内容宽 1140px，搜索宽 570px，宽屏组件基于 180px 卡片与 60px 间隔，时钟横跨两列。手机组件两列、常用四列，使用导航抽屉。日历按本地公历、周一为首列；支持六周月份和跨年。

三张壁纸由 ImageGen 根据风景描述生成，仅做尺寸与 WebP 编码优化。全图总计约 748 KB，缩略图约 50 KB；不使用运行时外部图片地址。内置壁纸选择来自白名单；CSP 的图片来源允许同源、data: 和本地 Blob URL，未开放外部图片域名。

## 本地背景图库

主页设置的“本地图库”支持多选导入、预览、选择和逐张删除。所有变化先保留在内存，统一保存后持久化，取消恢复已保存背景；切回内置壁纸不会删除图库。删除当前选中的本地图片后，预览账号保存的内置壁纸。支持 JPEG、PNG、WebP、GIF，单张源文件最多 20 MiB、4000 万像素，按比例缩小至最长边不超过 3840px，以质量 0.85 编码为静态 WebP；动态图取首帧，保留透明通道。另生成最长边 320px 的缩略图，原文件不保留。每账号压缩后的主图与缩略图合计最多 100 MiB，浏览器实际可用空间可能更少。

浏览器数据库 `luypage-wallpapers` v1 使用 `images`（主图 Blob）、`metadata`（名称、尺寸、大小及缩略图）和 `state`（当前选中 ID 与本地版本号）三个仓库，均按账号 ID 隔离。首页只读取当前主图，打开设置后才加载图库缩略图；Blob URL 在替换、关闭和卸载时释放。退出登录清理页面内存并保留已保存图库；清除网站数据、浏览器存储回收或无痕会话结束可能丢失图库，自定义背景不随账号同步，也不属于服务端备份。

本地草稿与账号偏好分开管理，HTTP API 与 D1 结构不变。只改图库不发送账号偏好 PUT；同时修改时先保存账号偏好，再用一个 IndexedDB 事务提交图片增删、选择状态和本地版本。事务 complete 才视为本地保存成功。账号失败不写图库；账号成功、本地失败时明确提示部分成功，保留图库草稿，重试不重复发送已成功的账号操作。取消不会撤销已成功的账号设置。

本地保存检查图库版本，拒绝覆盖其他标签页的更新；重新载入图库须确认放弃本地草稿，账号设置草稿保留。账号冲突读取最新账号设置时也保留图库草稿。主页重新获得焦点会刷新已保存背景，编辑中的预览保持独立。空间不足、事务中止、数据库打开失败或升级阻塞均给出错误与恢复入口；数据库失败不阻止保存搜索方式、时钟等账号偏好。主图缺失或损坏时回退到内置背景。

## 验证

视觉检查与截图见项目根目录 `design-qa.md`。本地预览使用 `/tmp/luypage-home-preview` 中的隔离数据库；其中示例收藏只用于本轮视觉验收，不是产品内置数据，不影响 `.wrangler/state` 或线上账号。

生产 CSP 用例直接加载本次构建产物并施加真实 `_headers` 策略，验证背景与缩略图正常显示、背景操作无新增 CSP 违规。既有 Zod 依赖初始化会探测 eval，遭脚本 CSP 拦截后自动回退；测试单独记录该初始化行为，未放宽脚本策略。Playwright 启动前端服务前先构建，避免此检查读取过期产物。
